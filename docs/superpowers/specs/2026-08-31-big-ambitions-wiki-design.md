# Big Ambitions Wiki 复刻站设计

## 目标

在现有 `Big Ambitions` 项目目录内创建一个以 Big Ambitions 为主题的攻略站。站点在布局、信息层级、间距、组件形态与响应式行为上参照 `gamblewithyourfriends.net`，但使用 Big Ambitions 的原创文案、已核实资料和自有视觉元素，不复制参考站的品牌、Logo、图片或文章正文。

## 技术方案

- Next.js App Router 与 TypeScript。
- React 服务端组件为主，只有移动导航和语言切换等交互使用客户端组件。
- MDX 保存攻略文章正文和文章元数据。
- 项目内语言词典负责公共界面文字；首期提供英语和德语。
- CSS Modules 或全局 CSS 变量实现参考站的深色视觉、黄色强调色、卡片、文章排版和响应式布局。
- 不依赖外部 CMS、数据库或运行时 API。

## 路由

- `/`：跳转到 `/en`。
- `/en`、`/de`：对应语言首页。
- `/en/mods`、`/de/mods`：Mods 列表和导航页。
- `/en/mods/big-ambitions-mods`、`/de/mods/big-ambitions-mods`：MDX 文章详情页。
- 对无效语言或不存在的文章返回 Next.js 404 页面。

以上路由构成至少三个独立页面类型：主页、列表/导航页和文章详情页。

## 视觉与布局

### 全站

- 黑色固定顶栏，左侧为 Big Ambitions Wiki 品牌区，中间为主导航，右侧为 Steam 行动按钮。
- 主背景使用接近黑色的深色，正文使用高对比白色与灰白色。
- 黄色用于标题强调、标签、按钮、激活导航和关键数据。
- 标题采用紧凑、厚重的展示字体风格，正文采用清晰的无衬线字体。
- 页脚保留参考站的多列链接与免责声明结构。

### 首页

- 居中英雄区：更新标签、大标题、简介、两个行动按钮。
- 英雄区下方为四个核心数据卡片。
- 游戏介绍区使用正文与特点卡片。
- 攻略入口使用三列卡片网格，移动端改为单列。
- 页面下方包含新手提示、常见问题和最终行动区。

### Mods 列表页

- 顶部使用面包屑、分类标签、标题与简介。
- 主体展示 Mods 相关内容卡片，包括模组介绍、安装与安全提示、Blueprints 和故障排查入口。
- 列表项链接到具体 MDX 文章详情页。
- 页面内容与 Big Ambitions 当前实际模组生态保持一致，不虚构官方 Workshop 或模组支持。

### 文章详情页

- 顶部包含面包屑、主题标签、标题和摘要。
- 正文采用参考站的窄栏文章结构，支持标题、段落、列表、提示框、步骤卡、表格和 FAQ。
- 桌面端保留右侧广告/辅助栏占位结构；移动端隐藏或移到正文后方。
- 文章结尾提供返回 Mods 列表和 Steam 页面按钮。

## 内容与数据

- 使用 `keywords-bigambitions.json` 决定站点内容入口和页面关键词。
- 使用 `关键词素材-bigambitions.md` 中已核实的官方来源与资料撰写内容。
- 文章正文手工写入 MDX，不在构建时抓取第三方页面。
- 官方链接仅使用可访问的 Big Ambitions 官网、Steam、Discord、Reddit、论坛和官方 YouTube。
- 竞品攻略站链接不进入页面。
- 未确认的平台、模组或发布日期信息明确标注为未确认，不作为事实陈述。

## 国际化

- `en` 为默认语言，`de` 为第二语言。
- 公共导航、按钮、页脚和页面摘要由类型安全的语言词典提供。
- MDX 正文按语言分目录存放，避免在同一文档中混合翻译。
- 语言切换保持当前页面类型与文章 slug；不存在对应翻译时回到该语言的 Mods 列表页。
- 页面设置正确的 `lang` 属性，并生成对应语言的标题和描述。

## 组件边界

- `SiteHeader`：品牌、桌面导航、移动菜单、Steam 按钮、语言切换。
- `SiteFooter`：站点说明、攻略链接、官方链接和免责声明。
- `Hero`：首页主视觉和行动按钮。
- `StatsGrid`：核心数据。
- `GuideCard` / `GuideGrid`：攻略入口。
- `Breadcrumbs`：列表和文章层级导航。
- `ArticleHeader`：文章标签、标题和摘要。
- `MdxComponents`：MDX 标题、提示框、表格、步骤和链接样式。
- `content` 模块：读取、校验和返回指定语言的 MDX 内容及元数据。

## 错误处理

- 未知语言、未知 slug 和缺失 MDX 文件使用 `notFound()`。
- 外链均使用安全属性，并在内容录入时只采用已核实链接。
- MDX 元数据缺少必填字段时在构建阶段失败，而不是渲染空白内容。
- 图片采用本地资源；不存在图片时显示设计一致的纯 CSS 占位，不请求未知远程图片。

## 验证

- 安装依赖后运行类型检查、代码检查和生产构建。
- 验证英文和德文的主页、Mods 列表页、文章详情页均可访问。
- 验证无效语言与无效文章返回 404。
- 在桌面与移动视口逐页截图，与参考站核对顶栏、英雄区、卡片、文章宽度、字体层级和页脚。
- 检查页面没有目标站的品牌文案、Logo或受版权保护图片。
- 检查内容来源于本项目资料，且没有失效的站内链接。
